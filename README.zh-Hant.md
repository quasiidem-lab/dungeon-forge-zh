# 地城鍛造廠（Dungeon Forge 繁體中文版）

程序化地城產生器：給一個種子，即時長出一座完整的立體地城，並且可以一階一階看它蓋起來。
同一個種子永遠產生同一座地城。

**線上版**：https://quasiidem-lab.github.io/dungeon-forge-zh/

本專案改自 [majidmanzarpour/threejs-procedural-dungeon](https://github.com/majidmanzarpour/threejs-procedural-dungeon)，
原作者 Majid Manzarpour，MIT 授權。原始的英文說明見 [README.md](README.md)。

## 操作方式

| 動作 | 操作 |
|---|---|
| 平移 | 左鍵拖曳 |
| 轉視角 | 右鍵拖曳（或 Shift + 左鍵） |
| 縮放 | 滾輪 |
| 重新鍛造 | `R` |
| 換主題 | `T` |
| 連通圖疊層 | `G` |
| 難度熱區圖 | `H` |
| 後製特效 | `P` |
| 跳過建造動畫 | 空白鍵 |

## 這個版本改了什麼

相對於原專案，只有兩處改動。

### 1. 介面與產生內容的繁體中文化

面板、滑桿、圖例、統計、操作提示全部中文化，五個主題改為
遠古／熔火／霜寒／陰森／蒼翠，房間類型改為入口／戰鬥／精英／寶藏／神龕／首領。

地城名稱產生器是**重寫而非直譯**。原本的格式是 `The Sunken Halls of Mal'goth`
（冠詞＋形容詞＋名詞＋of＋人名），中文沒有冠詞且所有格在前，因此改為
`瑪爾戈斯的沉沒地窖` —— 擁有者在前，修飾語與本體在後。

**詞庫的長度與順序刻意保持不變**（每個主題 8 個形容詞、8 個名詞，音譯表 12＋12）。
亂數是靠索引取值的，長度一變，同一個種子就會抽到不同的詞。維持原長度，
既有的種子才會產生與原版結構完全相同的地城，只是名稱變成中文。
**日後增修詞庫時務必整組等量增減，否則所有既有種子會全部失效。**

未中文化的部分：`FPS`（中文圈慣用英文）、`data-t` / `data-o` 等
HTML 屬性（那是程式碼用的鍵，改了會直接壞掉）、原作者的社群分享 meta 標籤。

### 2. 視角俯角解鎖

原本的俯角被鎖在 `[0.32, 1.15]` 弧度（約 18°～66°），固定在等距的四分之三視角。
改為 `[0.10, PI/2 - 0.02]`，讓相機可以拉到接近正上方的純俯視，
方便當作跑團戰棋地圖使用。

上限刻意停在差 0.02 弧度（約 1.1°）處而非剛好 90°：在完全垂直時，
相機的前向量會與 `lookAt` 的上向量平行，座標基底退化，畫面會突然跳成一個
任意的水平轉角。留這點餘裕即可完全避開，而肉眼看不出差別。

角度上下限抽成 `PITCH_MIN` / `PITCH_MAX` 兩個常數（原本硬編碼散在兩處），
之後要再調整只需改一行。

## 本機執行

需要 Node 18 以上。

```bash
npm install
npm run dev      # 開發伺服器，預設 http://localhost:5173/
npm run build    # 打包到 dist/
```

**不能直接用瀏覽器開 `index.html`** —— 原始碼使用 ES module import，
以 `file://` 開啟會被 CORS 擋下，必須透過伺服器。

## 部署

推送到 `main` 分支後，GitHub Actions 會自動打包並發布到 GitHub Pages
（設定見 [.github/workflows/deploy.yml](.github/workflows/deploy.yml)）。
`dist/` 不進版控，由 CI 產生。
